# OPEN//77 RP

Русскоязычный RP-сервер для мультиплеерной платформы OPEN//77 и Cyberpunk 2077.
Проект переделывает исходную Freeroam-сборку в сервер со своими персонажами,
экономикой, инвентарём, работами, фракциями, медициной, полицией, транспортом,
киберимплантами и ролевыми интерфейсами.

Проект находится в активной разработке. Большая часть серверной логики написана
на Lua, игровые окна — на HTML/CSS/JavaScript. Состояние хранится в MariaDB, а
деньги и предметы проводятся через системный `open77_transactions`.

## Контекст для продолжения разработки

**Claude Code (VS Code):** открой корень репозитория. Claude автоматически прочитает [`CLAUDE.md`](CLAUDE.md); сразу после этого изучи [`HANDOFF-CLAUDE.md`](HANDOFF-CLAUDE.md), `git status`, последние коммиты и локальные изменения. Подробная инструкция: [`docs/CLAUDE-QUICKSTART.md`](docs/CLAUDE-QUICKSTART.md). Не удаляй локальные файлы и не меняй одобренную вкладку имплантов без нового запроса.


- [`HANDOFF-CLAUDE.md`](HANDOFF-CLAUDE.md) — актуальный технический handoff: последние механики, нюансы и правила для Claude Code.
- [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) — краткая точка входа для ChatGPT и
  других помощников: архитектура, текущее состояние и правила работы.
- [`CLAUDE.md`](CLAUDE.md) — краткие рабочие инструкции, автоматически читаемые Claude Code.
- [`docs/PROJECT_HISTORY.md`](docs/PROJECT_HISTORY.md) — **полный архив** исторических решений прежнего `CLAUDE.md`.
- [`docs/RESOURCE-MAP.md`](docs/RESOURCE-MAP.md) — карта всех 30 игровых ресурсов и их связей.
- [`.claude/rules/`](.claude/rules/) — отдельные scoped-правила для OPEN//77 Lua и WebUI.
- [`DOCS.md`](DOCS.md) — документация владельца сервера, настройки и команды.
- [`TESTING-2P.md`](TESTING-2P.md) — сценарии проверки механик двумя игроками.

Перед изменением проекта прочитай `HANDOFF-CLAUDE.md`, затем `PROJECT_CONTEXT.md` и нужные разделы `DOCS.md`. Приоритет имеют фактический код, состояние `git diff` и пользовательские файлы, а не прошлые планы. На 2026-11-01 локальная детализированная голограмма Риперов может не совпадать с векторным SVG на GitHub; не затирай её при синхронизации.

## Структура

```text
resources/rp/       собственные игровые ресурсы
tools/              локальные инструменты разработки
server.jsonc        конфигурация OPEN//77 без секретов
acl.jsonc           права владельца сервера
CLAUDE.md            краткое auto-loaded руководство для Claude Code
HANDOFF-CLAUDE.md    актуальное руководство для продолжения разработки
docs/                история, старт Claude Code, карта ресурсов
.claude/rules/        правила для конкретных файлов Lua и WebUI
DOCS.md              эксплуатационная документация
TESTING-2P.md        ручные тесты на двух клиентах
```

Системные ресурсы OPEN//77, бинарники сервера, логи, кэш, ключи, локальная база
и переменные окружения намеренно не входят в репозиторий.

## Важные ограничения

- OPEN//77 не является FiveM: события, permissions и native-функции нельзя
  угадывать или переносить по аналогии.
- Сервер авторитетен; игрока нельзя менять до готовности его сессии и тела.
- Деньги и предметы должны изменяться атомарно через `open77_transactions`.
- Клиентские изменения публикуются игрокам только после `refresh` и перезахода.
- Все пользовательские интерфейсы и игровые тексты проекта ведутся на русском.

Это рабочий RP-проект, а не готовая универсальная сборка. Для запуска нужны
легальная копия Cyberpunk 2077, OPEN//77 и отдельно установленные системные
ресурсы, перечисленные в документации.
