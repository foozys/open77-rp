# Проверка вкладки имплантов

`check-implants.cjs` открывает настоящий HTML ресурса в headless Chrome.
Транспорт `Open77` подменён только внутри браузерного теста. Игровой сервер,
БД и живые данные не используются; тестовые предметы не входят в WebUI.

Нужны Node.js, установленный Chrome и Playwright. Пример PowerShell из корня
репозитория, с установкой зависимости вне проекта:

```powershell
$uiTestDeps = Join-Path $env:LOCALAPPDATA 'open77-ui-check'
npm.cmd install --prefix $uiTestDeps --no-save --package-lock=false playwright@1.64.1
$env:PLAYWRIGHT_MODULE = Join-Path $uiTestDeps 'node_modules/playwright'
node tools/ui/check-implants.cjs
```

Для Edge установить `$env:BROWSER_CHANNEL = 'msedge'`. По умолчанию результаты
сохраняются в `output/implants-check` (вне Git); переопределение — `UI_CHECK_OUTPUT`.

Проверяется:

- синтаксис встроенного JS, уникальность статических DOM ID, сохранность
  существующих входящих событий и объявление всех новых ассетов в манифесте;
- 1920×1080, 2560×1440, 1600×900, 1366×768, 1280×720 и 2560×1080:
  12 слотов, отсутствие обрезки и перекрытия кликабельных карточек;
- подсказка, подсветка, новые серверные значения, предупреждения, пустые и
  полностью занятые слоты, дополнительная неизвестная категория;
- открытие деки мышью/клавиатурой, Tab, Esc, клик вне окна, сохранение фокуса
  при обновлении, команды вставки/извлечения с Lua-индексом 1, заполненная
  дека, предупреждение без Kiroshi, очистка подсказок при закрытии;
- точное равенство снимков инвентаря с HTML из `git show HEAD:...` на
  1920×1080 и 1280×720, включая возврат из вкладки имплантов. При сравнении
  CSS-переходы завершаются, чтобы не сравнивать промежуточные кадры;
- отсутствие ошибок JS и HTTP 4xx/5xx при загрузке ассетов.

Снимки `implants-*.png` и `result.json` — артефакты проверки. Для первого
внедрения эталон HEAD — полученный с GitHub коммит `d93da6b`. После коммита
нового дизайна HEAD становится эталоном для следующих изменений.

Тест **не подтверждает** игровую доставку ресурса, FPS в CEF, Lua-транзакции,
drag/drop, обыск или работу настоящего сервера. Для них остаётся ручная
проверка в `TESTING-2P.md`. Папка `design-backups` тестом не читается и не меняется.
