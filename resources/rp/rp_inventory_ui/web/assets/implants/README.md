# Графика вкладки имплантов

Создана встроенным `image_gen` по согласованному владельцем концепту 2026-11-01.
Промпты сохранены в `generation-prompts.json`. PNG содержат альфа-канал;
это отдельные иллюстрации без нарисованных подписей, рамок и игровых значений.

- `body-v1.png`: 793 × 1983, фронтальная анатомическая проекция. SVG `#cyBody`
  использует тот же viewBox, а независимые SVG-области отвечают за подсветку.
- `icons-v1.png`: 1448 × 1086, атлас 4 × 3; каждая ячейка 362 × 362.
  Порядок по строкам: eyes, os, arms, skeleton / tendons, skin, heart, blood /
  metabolism, ice, purge, legs. Раскладка определена в `CY_ART`.

Иконки обозначают **типы имплантов**, а не точные модели из оригинальной игры.
Например, разные ОС используют общую иллюстрацию категории `os`. Название,
описание, цена человечности, доступность и число скриптов всегда приходят
с сервера. Для неизвестного слота сохранена существующая SVG-иллюстрация.

Оба PNG и `implants.css` явно опубликованы через `web_files` в `open77.lua`.
Загрузка идёт относительными URL внутри ресурса, без CDN и без передачи
изображений через события Lua. README и промпты клиентам не публикуются.

При замене рисунка тела необходимо согласовать координаты подсвечиваемых
областей и `data-anchor` в SVG. При замене атласа сохранять равные ячейки,
прозрачные поля и порядок `CY_ART` либо обновить отображение.
