# RIPPER//77 — хирургический терминал, визуальная переработка

Дата: 2026-11-01. Ветка: `main`.

## Что изменено

**Ресурс:** `resources/rp/rp_surgery_ui`. Новая полноэкранная художественная оболочка операционного WebUI (REDLINE: насыщенный бордовый, голубой медицинский, янтарные статусы). Это **не** личная вкладка «Импланты» инвентаря: интерфейс последней остаётся без изменений, как потребовал владелец проекта.

В экран встроены:
- режим **подбора импланта** с группами слотов вокруг отдельной анатомической голограммы, иконками разных органов, данными ID пациента и выбором конкретной операции;
- **согласие пациента**: крупная карточка предложения и предупреждение о рисках, собственные кнопки «Отказаться» / «Подтвердить»;
- две **мини-игры операций**: снятие через последовательность разрезов красных точек на кабелях и установка через соединение нейронов и проводов; подложка, терминалы, телеметрия и индикаторы интерфейса переработаны;
- визуальная строка «Диагностика → Согласие → Операция». Это **информационный индикатор**, а не управление этапами; реальный порядок и разрешения определяет сервер.

Новая иллюстрация тела: `web/assets/patient-hologram.svg`. Стили отдельно в `web/surgery-redline.css`, обе зависимости внесены в `open77.lua`.

## Не трогали

- Оригинал целиком сохранён: `design-backups/rp-surgery-ui-before-redesign.html`.
- `resources/rp/rp_surgery_ui/client/main.lua` и все серверные Lua-ресурсы — без изменений.
- События WebUI `surgery:choose`, `surgery:offer`, `surgery:consent`, `surgery:consentReply`, `surgery:game`, `surgery:submit`, `surgery:stage`, `surgery:finish`, `surgery:close`, `ui:ready` — без новых параметров и переименований.
- Алгоритмы игр, вычисление пересечений точек, система улучшения навыка Рипера, таймер, красные маркеры и условия отправки результата — не менялись.
- `rp_inventory_ui`, `rp_cyberware_ui`, личная вкладка имплантов и Ripper-продажи — не менялись.

## Проверки

Статическая проверка выполнена: JS компилируется, все ID исходного DOM присутствуют, дублей ID нет, все старые `Open77.on` и `Open77.emit` присутствуют, количество кодовых привязок обработчиков кликов/hover не изменилось. Ресурсы CSS/SVG присутствуют в GitHub, оба пути включены в `web_files`.

**Не подтверждено:** вид и управление в реальном игровом WebUI. Следующие пункты надо проверить в игре с рипером и пациентом:

1. Врач вызывает ALT → «Предложить установку импланта», открывает карту пациента; все 12 слотов видны, карточки реагируют на наведение, в центре подсвечивается орган.
2. Нажатие по занятому слоту предлагает **снятие** даже при пустых карманах пациента; установка доступна только для совместимых имплантов в инвентаре пациента; замена не скрыта.
3. Кнопка «Назад к слотам» возвращает к карте без подтверждения сделки.
4. Пациент видит точные названия имплантов и врача, может отказаться или согласиться; никакая операция не запускается без согласия.
5. При установке в мини-игре соединение по парам учитывает реальные номера, подсвечиваются выполненные соединения, отправляется результат.
6. При снятии все красные маркеры видимы, включая **последний провод**; нажатие на верную/неверную точку отправляет правильный номер; очерёдность не меняется.
7. Таймер идёт, кнопка закрытия блокируется во время мини-игры; по завершении отображается результат и интерфейс закрывается.
8. 1920×1080, 1600×900, 2560×1440: ничего не обрезается без возможности прокрутки. Проверить обе мини-игры (кабели не перекрыты телеметрией).
9. Не появляются ошибки загрузки `surgery-redline.css` и `patient-hologram.svg` в WebUI.

## Как обновить и проверить

```bash
git pull --ff-only origin main
```

Полностью перезапустить сервер, переподключить оба клиента (манифест `reload_policy "reconnect"`).

## Откат

Для отката восстановить содержимое `design-backups/rp-surgery-ui-before-redesign.html` в `rp_surgery_ui/web/index.html` и убрать необязательные ссылки на внешние ассеты. Код Lua и саму хирургию откатывать не требуется.

## Что сравнивать с вариантом Astra

Сравнивать именно **выполненный UI в игре**: графику тела, плотность композиции, карточки органов, удобство выбора и читаемость кабельной мини-игры. Изолированная картинка-концепт не считается результатом. Это первая художественная версия, пока без подтверждённой визуальной приёмки.
