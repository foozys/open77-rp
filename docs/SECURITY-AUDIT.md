# Аудит сетевых событий `rp_*` (шаг 3, подзадачи 3.1–3.2)

> Составлено 2026-11-02 по коду рабочего дерева (`main` после `e16d255`). Платформенные факты сверены
> с devkit MCP (индекс 2.50.0+op77.156): `RegisterNetEvent`, `Open77.net.register`,
> «The Lua resource runtime › Local and network events».
> Аудит **статический**: по коду, без игры. Находки — подзадачи «Исправление: …» в `docs/ROADMAP.md`.

## Что гарантирует платформа (devkit)

- В обработчике `RegisterNetEvent` глобальный `source` берётся из аутентифицированного соединения;
  подделать чужой `source` клиент не может. Аргументы — любые: проверять всё.
- **`source` может перезаписать другая задача через `Wait` / `:await()`** — в обработчике с ожиданием
  его нужно сразу сохранить в локальную переменную.
- Пакеты получают только обработчики, явно объявленные сетевыми. `RegisterNetEvent("имя")` **без
  функции** открывает клиенту это имя — и тогда до клиента доходят все `AddEventHandler` с ним.
- Обработчик `RegisterNetEvent` получает и локальные `TriggerEvent` с тем же именем.
- Аргументы: `nil`, boolean, конечные числа, строки, таблицы; не более 32 аргументов и 48 КиБ.
