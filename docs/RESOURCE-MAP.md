# Карта ресурсов OPEN//77 RP для Claude Code

Сверено с `resources/rp/` и `server.jsonc` в `main` на 2026-11-01. Это **индекс по назначению**, а не подтверждение, что каждая механика протестирована в игре. Первичный источник — `open77.lua` каждого ресурса и код.

## Ядро и персонажи

| Ресурс | Назначение / где смотреть |
|---|---|
| `rp_core` | Аккаунты, персонажи, ACL/роли, whitelist, MariaDB, миграции, ready gate; `server/config.lua`, `server/characters.lua`, `server/roles.lua`, `server/main.lua` |
| `rp_charselect` | Экран выбора/создания персонажа, анкета, предыстория и фракция |
| `rp_factions` | Постоянное членство во фракции, конфигурация и лимиты слотов |
| `rp_jobs` | Работа, ранги, смены, зарплата; не путать с фракцией |
| `rp_player_ids` | ID игрока вместо ника над головой |
| `rp_clothes` | Передача модовой причёски Roxy, не стандартный гардероб F2 |
| `rp_chat` | Ролевой чат |
| `rp_hud` | HUD денег и состояния |
| `rp_needs` | Голод, жажда и потребление еды |

## Связи, которые легко сломать

- **Личная вкладка имплантов:** `rp_inventory_ui` ↔ `rp_inventory` и `rp_cyberware`. Владелец принял текущий дизайн вкладки. Не затрагивать её в редизайне хирургии.
- **Хирургия Риперов:** `rp_surgery_ui/client/main.lua` → серверные события `rp_surgery` → серверный API `rp_cyberware`/инвентаря/медицины. Установка и снятие не должны решаться только клиентом.
- **Транзакции:** `rp_money` / `rp_inventory` / `rp_shops` / `rp_contracts` используют `open77_transactions` из внешнего `resources/system`. Не добавляй его в Git.
- **Конфигурация ресурсов:** `server.jsonc` → `resources.load`. Клиентский ресурс не должен зависеть от server-only ресурса.
- **Публикация WebUI:** `web_file` + `web_files` в манифесте, затем серверный `refresh` / restart сервера и reconnect клиента.
- **Графика Рипера:** в GitHub `patient-hologram.svg` всё ещё векторный; локальный вариант с PNG может быть только в рабочей копии владельца. Не затирай локальную работу при `pull`.
