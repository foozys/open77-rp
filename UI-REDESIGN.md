# UI REDESIGN V3 — инвентарь / импланты

Статус: реализована новая визуальная версия в `main`; **ручной тест в игре и визуальная приёмка владельцем ещё не выполнены**.

## Цель и художественное направление

Два пользовательских референса: широкоформатный тёмный RED/CYAN Cyberpunk HUD с детальными подсвеченными ячейками предметов, большим оборудованием справа, левой вертикальной навигацией, анатомической проекцией по центру и связями от слотов к органам.

В отличие от V1/V2 это не только смена темы: изменены структура шапки, контейнеры рабочего места, навигация, рамки рабочей сетки и оснащения; подключены локальные SVG-иллюстрации и детализированная проекция.

## Контракт игрового UI (не ломать)

Существующий клиент `rp_inventory_ui/client/main.lua` и сервер `rp_inventory/server/main.lua` должны работать без новых экспортов/событий. Сохранять функции и ID:
- `#root`, `#panel`, `#tabs`, `#invView`, `#cyberView`;
- `#grid`, `#lootGrid`, `#lootGear`, `#gearBox`, `.wslot`, `.bslot`;
- `#ghost`, `#tooltip`, `#menu`, `#dialog`, `#overflowList`;
- `#cyLeft`, `#cyRight`, `#cyBody`, `#humMeter`, `#sanMeter`, `#deckBox`;
- сетевые сообщения `inv:state`, `inv:catalog`, `inv:cyber`, `inv:open`, `inv:close`;
- вычисление коллизий и размеров предметов/перетаскивания — JS `CELL=76` и CSS `--cell:76px` должны совпадать.

Визуальные кнопки «Персонаж» и «Статистика» пока не являются функциональными вкладками; не изображать их как рабочие. UI игры отрисовывается по сохранённым серверным данным: новая графика не должна подменять предметы или их доступность.

## Откат

Вернуть содержимое `design-backups/inventory-and-implants-before-redesign.html` в `resources/rp/rp_inventory_ui/web/index.html` отдельным коммитом, затем `git pull --ff-only origin main`, полностью обновить ресурсы и переподключить игроков. Сохранить также резервную V2.

## Где посмотреть результат

После `git pull --ff-only origin main` перезапустить сервер, переподключить клиент и открыть `I`. Вкладка инвентаря отображает сетку и оснащение, вкладка имплантов — анатомию и слоты. Внешний вид зависит от движка WebUI и конфигурации разрешения клиента.
